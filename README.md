# arca-creative-concepts

Website for **ARCA Creative Concepts** — a Barbados-based, family-run studio making handmade knit, crochet, sewing, and jewelry pieces, and teaching crochet and dressmaking classes.

🔗 Live site: [allisonh-64.github.io/arca-creative-concepts](https://allisonh-64.github.io/arca-creative-concepts/)

## About

ARCA's name comes from two stories: **ARCA** spells out the initials of the family behind it (Allison, Renee, Carlene, and Allison), and **Creative Concepts** nods to the notions pictured in the family's own logo — the scissors, thread, pins, and yarn behind every piece.

The site covers:

- **Home** — an introduction and a look across all four crafts
- **Our Work** — a gallery of knit, crochet, sewing, and jewelry pieces, including work made for past customers
- **Classes** — crochet (through the Wesleyan Holiness Community Service Program) and dressmaking (through the Calvary Institute)
- **Commission a Piece** — how to request a custom order
- **About** — the family's story
- **Contact** — email, phone, and a message form

## Tech

This is a single self-contained `index.html` file — all HTML, CSS, and JavaScript (plus the site's images, embedded directly) live in one file. There's no build step and no dependencies to install; it's a static page that runs entirely in the browser.

## Running locally

Just open `index.html` in any web browser.

## Deploying

This repo is set up to be hosted with **GitHub Pages**:

1. Go to this repository's **Settings → Pages**.
2. Under "Source," select the `main` branch and the root folder.
3. Save — GitHub will publish the site at `https://<your-username>.github.io/arca-creative-concepts/`.
4. Optional: add a custom domain (e.g. `arcacreativeconcepts.com`) in the same Pages settings screen, and point your domain's DNS to GitHub as instructed there.

## Updating the site

Since everything lives in one file, updates mean editing `index.html` directly (or replacing it with a newer exported version) and pushing the change to this repository — GitHub Pages will pick it up automatically.

See [CHANGELOG.md](CHANGELOG.md) for a history of what's changed.
